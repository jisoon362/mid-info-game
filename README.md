# 중학교 정보 수업 게임 모음

학생 태블릿 브라우저에서 링크로 여는 수업용 게임 모음입니다. GitHub Pages로 배포합니다.

## 폴더 구조

```
index.html              게임 목록 화면 (학생에게 나눠 줄 첫 화면)
games.js                목록에 보일 게임 정보 (번호, 이름, 영역, 단원, 설명)
theme.js                밝은 모드 / 어두운 모드 전환 (모든 화면 공용)
games/
  01-card-move/         1번 게임: 카드 옮기기
    index.html
  02-relay-draw/        2번 게임: 이어 그리기 (추상화)
    index.html
```

## 새 게임 추가하는 법

1. `games/` 아래에 `02-이름/` 폴더를 만들고 그 안에 `index.html`을 넣습니다.
2. `games.js`의 목록에 한 줄을 추가합니다.
3. 커밋하고 올리면 목록 화면에 자동으로 나타납니다.

게임 화면의 「← 목록으로」 버튼은 `../../`(목록 화면)로 돌아갑니다.

## 배포 (GitHub Pages)

저장소의 Settings > Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정합니다.
주소는 `https://<계정>.github.io/<저장소 이름>/` 입니다.

## 수업 코드

- 게임은 교시마다 바뀌는 3자리 수업 코드를 넣어야 열립니다.
- 선생님은 게임 첫 화면의 「선생님 메뉴」에서 지금 교시의 코드를 볼 수 있습니다.
- 학생 닉네임, 비밀번호, 기록은 각 태블릿 브라우저에만 저장되고 서버로 전송되지 않습니다.

## 학생 결과 모아 보기 (구글 시트)

2번 게임의 「선생님께 제출」과 `teacher/` 결과 보기 화면은 구글 시트에 연결해야 동작합니다.

1. 구글 시트를 새로 만들고 확장 프로그램 > Apps Script 를 엽니다.
2. `server/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 배포 > 새 배포 > 유형 "웹 앱", 실행 "나", 액세스 권한 "모든 사용자"로 배포합니다.
4. 나온 웹 앱 URL(`.../exec`)을 `config.js`의 따옴표 안에 넣습니다.

결과 보기 화면: `teacher/` (선생님 비밀번호 필요)
